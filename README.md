# The Last son of Hope

3D-симулятор супергероя от третьего лица в браузере.
Полёт от улиц мегаполиса до Луны, сверхзвуковые скорости, мощные удары, броски машин и разрушаемый живой город.

> Личный проект, вдохновлённый другими вселенными о супергероях.
> Собственные персонаж, название и мир.

## Идея

Почувствовать себя всемогущим героем: летать, разгоняться до сверхзвука и рушить здания — с реалистичной физикой, графикой и звуком.

- **Сейчас:** управление клавиатурой и мышью.
- **Дальше:** управление руками в реальном времени через камеру (MediaPipe + OpenCV).

## Запуск

Нужны **Python 3** и интернет (движок Three.js загружается с CDN).

1. Дважды кликни `start.bat` — запустится локальный сервер и откроется браузер.
2. Нажми «Играть».

Или вручную, из папки проекта:

```bash
python server.py 8000
```

и открой http://localhost:8000.

Подсказка с управлением показана в самой игре (`H` — скрыть).
