# The Last son of Hope — Version 3

> Это наш пока личный проект, вдохновлённый другими вселенными.
> Собственные персонаж, название и лор; сходства возможны, копий нет.

3D-симулятор супергероя от третьего лица.
Полёт от улиц до Луны, сверхзвук, удары, броски машин и разрушаемый живой город.
Version 3 — про реалистичную графику, человеческого персонажа и физику.

Этап 1 (сейчас): управление клавиатурой и мышью.
Этап 2 (дальше): управление руками в реальном времени через MediaPipe + OpenCV.

## Запуск

1. Дважды кликни `start.bat`. Он запустит локальный сервер (`server.py`) и откроет браузер.
2. Нажми «Играть».

Или вручную, из папки проекта:

```bash
python server.py 8000
```

и открой http://localhost:8000.

> Нужен интернет: библиотека Three.js загружается с CDN.
> Просто открыть `index.html` двойным кликом не получится: браузеры не загружают JS-модули с диска.
> `server.py` отключает кэш браузера, поэтому после обновления кода достаточно перезагрузить страницу.
> `Ctrl` в игре не используется: в браузере `Ctrl+W` закрывает вкладку.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение (в полёте — туда, куда смотрит камера) |
| Мышь | поворот камеры |
| `Space` | вверх / взлёт |
| `C` | вниз |
| `Shift` | сверхскорость (с `W`); в космосе — до 9 км/с; на земле — спринт |
| `Shift` + `E` | гиперскорость: в 3 раза быстрее (Mach 7,9 в атмосфере, 27 км/с в космосе) |
| `Shift` + `Q` | третий уровень ускорения: в 8 раз быстрее (Mach 21 в атмосфере, 72 км/с в космосе) |
| `B` или ЛКМ | удар (левой и правой по очереди); если в руках машина или обломок — удар по ним, они улетают |
| ПКМ (держать) | зарядка мощного удара, отпустить — удар |
| `R` | схватить ближайшую машину / обломок / человека, ещё раз — бросить |
| `Y` | рывок в сторону движения |
| `X` | удар о землю (в воздухе) |
| `T` | время суток: утро → день → закат → ночь |
| `U` | погода: ясно → облачно → дождь → гроза |
| `M` | следующий музыкальный трек |
| `G` | качество графики (высокое / среднее / низкое) |
| `K` | восстановить город |
| `H` | скрыть / показать подсказку |
| `Esc` | пауза |

## Что нового в Version 3

**Персонаж**
- Реалистичное мужское тело со скелетом (Free Rigged Male Basemesh, см. «Авторство»): белый костюм, тёмно-красные перчатки с наручами, сапоги и пояс, своя эмблема-ромб, открытое лицо и короткая стрижка.
- **Длинный красный плащ** с физикой ткани: висит за спиной, развевается в полёте, не проходит сквозь тело.
- Все прежние анимации (полёт, удары, бег, захват) переносятся на кости модели.

**Физика полёта**
- Поворот ограничен перегрузкой (~100 g): чем выше скорость, тем шире дуга и сильнее занос.
- Крен в вираже, как у самолёта.
- Сопротивление воздуха зависит от высоты; в космосе персонаж летит по инерции.
- Резкий разворот назад — сначала воздушное торможение (отдельная поза), потом разворот.
- Сверхзвуковой полёт у земли выбивает стёкла в соседних зданиях.

**Разрушения**
- Блестящие осколки стекла, плиты перекрытий и ржавая арматура среди обломков.
- Дыры и трещины на стенах в месте удара.
- Пыль после обрушения висит в воздухе 10–20 секунд.

**Графика**
- Четыре типа фасадов: стеклянные небоскрёбы, кирпич, офисы с пилястрами, жилые дома с балконами; витрины на первых этажах.
- За окнами видны комнаты с объёмом (пол, потолок, стены, жалюзи), ночью в них горит свет.
- Затенение у основания зданий, контрастнее свет, голубее небо.
- Дороги: пешеходные переходы, краевая разметка, бордюры, плитка тротуаров, заплатки на асфальте.
- ~30 000 деревьев в парках, вдоль улиц и в пригороде: качаются на ветру, ломаются от ударов.

## Что было в Version 2

**Способности**
- **Захват и бросок** (`R`, удар по предмету в руках — `B`): машины поднимаются над головой, людей персонаж бережно несёт на руках. Брошенная машина пробивает здания и взрывается.
- **Рывок** (`Y`): мгновенный бросок на ~35 м с остаточными изображениями.

**Окружение и разрушения**
- **Здания из секций**: если выбить нижнюю часть, верхушка падает целым куском, наклоняется, ломается об уцелевшую часть (прогрессирующее обрушение) и задевает соседние здания.
- **Машины** ездят по дорогам по правилам полос; их можно сбить, поднять, бросить; после сильного удара они взрываются и горят.
- **Люди** гуляют по тротуарам, разбегаются от опасности, отлетают от ударных волн и потом встают (без жестокости).
- **Фонари** вдоль дорог ломаются; ночью светятся.
- **Заправки** взрываются огненным шаром и рушат всё вокруг.
- **Мосты** через реку разрушаемы: машины падают в воду.
- **Физика обломков**: куски сталкиваются друг с другом (складываются в кучи), отскакивают от стен и крыш, тяжёлые быстрые куски повреждают здания.

**Карта и космос**
- Город стал больше: центр с небоскрёбами, пригород с домиками, река с мостами.
- Горы со снежными вершинами, океан с пляжем на востоке, три городка вдали.
- **Космос**: чем выше, тем темнее небо; появляются звёзды и видна кривизна Земли с облаками и атмосферой. Можно долететь до **Луны** (кратеры, удар о поверхность).
- **Вход в атмосферу**: огненный кокон при падении с орбиты на большой скорости.

**Графика и звук**
- Время суток и погода: закатное освещение, ночной город с горящими окнами, дождь, мокрый асфальт, гроза с молниями и громом.
- Зеркальные стёкла отражают небо; ночью в окнах горит свет.
- Звук по материалам: бетон, стекло, металл; взрывы, гром, дождь; ветер пропадает в вакууме.
- **Своя музыка**: положи mp3 (ogg, m4a) в папку `music/`, игра проиграет их по очереди (`M` — следующий).
- Качество графики (`G`). На встроенной графике (Intel и т.п.) игра сама включает среднее качество.

## Как будет подключаться управление руками (этап 2)

Игра читает только объект «намерений» игрока из `src/input.js`:

```js
{ moveX, moveZ, moveY, boost, hyper, lookDX, lookDY, punch, heavyHeld, slam, grab, dash }
```

Сейчас его заполняет `KeyboardMouseSource`. Для рук план такой:

1. Python-скрипт (MediaPipe Hands + OpenCV) распознаёт жесты и шлёт их по WebSocket (например, `ws://localhost:8765`).
2. В игре появится `HandSource`, который принимает эти сообщения и пишет в тот же объект.
3. Остальной код игры менять не нужно.

## Настройка

Почти всё регулируется в `src/config.js`: скорости, урон, радиусы ударов, размер города, количество машин и людей, туман, высота космоса, положение Луны.

## Отладка

В консоли браузера (F12) доступен объект `game`: `game.player`, `game.city`, `game.traffic` и т.д.
`game.sim(n)` прогоняет `n` кадров симуляции (используется для автопроверок).
